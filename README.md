# SuryaNexa Reworked — High-Velocity Solar EPC & SCM Landing Page

A modern Next.js 16 + React 19 landing page designed from scratch using the **Tactile Glass Bento** design system.

---

## 🎨 Visual Identity & Principles
- **Aesthetic**: Deep Industrial Slate (`#08090C`), Solar Amber (`#F59E0B`), Electric Sky (`#0EA5E9`), and Emerald (`#10B981`).
- **Zero AI Cliché**: No oversaturated generic purple radial glows or low-contrast washed-out text.
- **Physicality & Tactility**:
  - `LiquidGlassCard`: Specular radial spotlight tracking the user cursor coordinates.
  - `CursorTrailer`: Soft physical spring lag (`framer-motion`), disabled on mobile touchscreens.
  - `RooftopVisualizerSimulation`: Interactive satellite rooftop preview with real-time kW calculation, panel cycling, and instant dual-quotation switcher.

---

## 🏛️ Core Features Highlighted
